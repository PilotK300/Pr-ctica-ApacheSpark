## Contenido

Este repositorio contiene un cuaderno Jupyter desarrollado y documentado para practicar un flujo
básico de clasificación con Apache Spark y el conjunto de datos Iris.

El ejercicio incluye:

- creación de una SparkSession;
- exploración del conjunto Iris;
- indexación de la variable objetivo;
- construcción de vectores de características;
- escalamiento;
- división de datos;
- entrenamiento de Decision Tree, Random Forest y Naive Bayes;
- evaluación con accuracy;
- comparación de resultados.

## Ejecución

1. Abrir el archivo `.ipynb`.
2. Ejecutar las celdas de arriba hacia abajo.
3. Instalar PySpark desde la primera celda si hace falta.
4. Verificar que Java esté disponible.
5. Ajustar la ruta del conjunto Iris si se ejecuta fuera del entorno original de Kaggle.
